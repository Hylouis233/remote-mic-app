# 跨电脑语音输入

## 范围

公开 G9N9N 后端可将一次按住语音会话发送到用户配置的 Windows 电脑。
Mac 焦点下沿用现有本机语音链路；目标电脑焦点下，发送同一遥控器的真实 PCM 与语音按下/释放。
不以电脑麦克风替代遥控器，不读取输入工具私有文件，不采集剪贴板或输入文字。

## 目标选择

- 只使用用户明确选择的 Deskflow 公开日志中的进入屏幕、离开屏幕和断线事件。
- 有界读取日志尾部及新内容，不复制原始日志，不记录原始行。
- 电脑名和服务器配置由用户明确选择的公开配置提供；凭据、证书不进入本功能。
- 连接状态未知、来源进程退出或日志不可用时，不能猜测远端就绪。
- 在按下时确定一次会话的目标，不在一段话中切换音频目标。
- 功能默认关闭；用户配置 SSH 别名及已选日志路径后启用。本地路径和主机配置不进入公开仓库。

## 传输及目标电脑

- 使用系统 SSH 已有的主机认证和加密；BatchMode、严格主机密钥核对，无明文网络监听，无口令回退。
- Windows 中继只连接同一用户的受限命名管道。桌面组件以普通交互用户运行，不作为系统输入服务。
- 协议按长度分帧，单帧不超过 64 KiB；未知操作、错误长度和会话冲突明确失败。
- 音频固定为 G9 支持的 16 kHz、单声道、16 位 PCM；两端在途缓冲有上限。
- Windows 只输出到用户配置的虚拟声卡，不回退到物理扬声器；语音工具通过用户可见设置选择对应虚拟麦克风和按住快捷键。
- 两端组件复用各自系统登录启动；恢复电脑会话时重连公开G9链路，正常语音和尾音排空不得被恢复过程打断。
- 正常松开先完成已接收音频的自然播放及短尾部静音，再释放语音快捷键。
- 断线、背压、超时和取消释放按键，明确记录 forced 及中断样本数，不能记为正常排空。

## 隐私与生命周期

- 不保存、上传或记录原始音频和识别文字；SSH 的目的地仅为用户配置的电脑。
- Mac 诊断复用已有有界 AppLogger；Windows 仅按连接/会话事件记录类别、计数和结果，日志最多三份、每份 2 MiB、最长七天，在启动及写入时清理。
- 安装入口仅管理本组件的当前用户启动任务，卸载恢复自身改动；不停止或重配其他 Deskflow 组件。
- 自动化、音频设备读回和真实用户文字上屏分别报告；未完成双方切换、连续短句、长句及断线恢复实机测试前保持候选。
